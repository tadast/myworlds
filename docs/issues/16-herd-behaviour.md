# 16 Herd behaviour on the anchor

Type: HITL. Phase 2. Blocked by: 09, and a design session. Read `docs/fauna.md` "Ground tier".

## What to build

Behaviour between groups that attaches to the group anchor and never touches per-creature code: grazing that moves the herd along a slope, a predator group that stalks and makes a herd flee, a pair that circles a solitary animal, a swarm that lifts when a walker comes near.

## Needs a decision first

- Which two interactions come first.
- Whether a species gets a diet-based role from its lore, so the diet text and the behaviour agree.
- How far the reaction range is and how the flee resolves, so a herd does not run into the fog.

## Acceptance criteria

To be written after the design session.
